## Data Preparation

### Data Types

The code expects the following data formats:

- **Audio data**  
  16 kHz, 16-bit, single-channel `.wav` files

- **Video data**  
  `96 × 96` pixel, 25 FPS `.mp4` files for both face and lip videos  
  - Face videos follow the preprocessing style of LRS2/LRS3/VoxCeleb
  - Lip videos follow the preprocessing used in AVHuBERT or Auto-AVSR

- **Text data**  
  Lowercased and normalized text transcripts

- **Whisper features** *(used only for pretraining)*  
  `.npy` files with shape `(N_frames, Depth)`

  These files should be stored at the path generated by:

  ```python
  whisper_fn = audio_fn.replace("/audio/", "/whisper_fea/layer_last1/").replace(".wav", ".npy")
  ```
  where `audio_fn` is the path to the corresponding audio file. 
  
  The global mean and standard deviation file for Whisper features is expected at `/work2/asrprg/anonymous/lippretrain/extract_whisper_fea/whisper_last1.stat.npy`. This path is currently hard-coded in `models/hubert_distill_frm_whisper_offline_bestrq_dual_frontend.py`.

### Data Manifest

#### TSV file

The TSV file should follow this format:

- The first line is `/` or the root path.
- Each subsequent line should be formatted as:

```python
line = f"{uttid}\t{face_path}\t{lip_path}\t{audio_path}\t{video_frames}\t{audio_samples}\n"
```
See `../flare/data_demo/tsv_merge_face_lip_dataset/*.tsv`. If either the face video or lip video is unavailable, set the corresponding path field to `"null"`.


#### WRD file

Each `(i+1)`-th line in the `.wrd` file corresponds to the text transcript of the `i`-th entry in the TSV file.

See `../flare/data_demo/tsv_merge_face_lip_dataset/*.wrd`.

#### Dictionary and tokenizer files

- `../flare/data_demo/dict.km.txt` is a legacy file and is **not used**.
- `../flare/data_demo/dict.wrd.txt` is the BPE dictionary file.
- `../flare/data_demo/bpe_model` is the BPE tokenizer model used for finetuning.

#### Noise file

The noise file contains a list of waveform paths used for random noise augmentation during pretraining.

- Each line should contain the path to one noise `.wav` file.

See `../flare/data_demo/tsv_noise` for an example.
