# Code and Pretrained Models for *Learning Visual Speech Representations via Cross-Modal Distillation and Joint Face-Lip Modeling*

This repository contains the code and pretrained models for the paper *Learning Visual Speech Representations via Cross-Modal Distillation and Joint Face-Lip Modeling*.

## FLARE

The implementation and pretrained models for FLARE are provided in the `flare/` directory.

## FLARE-LLM

The implementation and pretrained models for FLARE-LLM are provided in the `flare-llm/` directory.
